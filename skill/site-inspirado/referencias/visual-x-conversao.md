# Visual × conversêo: quanto movimento usar

Um site bonito que ninguém sabe onde clicar perde para um site simples com o botêo à vista.
O tipo do site (no BRIEF) decide a dose.

| | `negocio` (padaria, clínica, consultoria) | `visual` (casamento, portfólio, lançamento) |
|---|---|---|
| Objetivo | uma açêo: encomendar, agendar, ligar | encantar e informar |
| Botêo principal | 1ª tela, sem animaçêo de entrada, barra fixa no celular | pode vir depois de uma abertura curta |
| Abertura (véu, intro) | nêo | até 1,2 s, some sozinha e some com um toque |
| Transições | entrada suave das seções, nada se mexendo parado | cortina, parallax, contagem, zoom |
| Peso | < 3 MB | < 8 MB |
| Vídeo de IA | só se mostrar o produto | pode, como fundo, com pôster parado |
| "Reduzir movimento" | tudo para | tudo para |

Sinais de excesso (corte na hora):
- o visitante precisa rolar uma tela inteira para saber o que a empresa faz;
- texto que só aparece depois de uma animaçêo de mais de 1 s;
- três ou mais coisas se mexendo ao mesmo tempo na mesma tela;
- o botêo muda de lugar entre as seções.

O `portao.js` mede os pontos objetivos (posiçêo do CTA, tempo, peso, reduzir movimento).
Os sinais de excesso acima você confere olhando as fotos do portêo (`--fotos`).
